ACE-Step 가사 생성 가이드

ACE-Step에서 가사 누락과 발음 깨짐 없이 자연스러운 노래를 만들려면 아래 형식에 맞춰 가사를 작성해 주세요.

1. 음절 수 제한 (가사 누락 방지)

한 줄당 공백 제외 6~10음절(3~4어절) 이내로 짧게 끊어 작성하세요(최대 12음절 이내). 1절([Verse 1])과 2절([Verse 2]), 각 후렴구([Chorus])의 대응하는 줄은 음절 수와 리듬감을 동일하게 맞추는 것이 좋습니다.

2. 한국어 발음 최적화 (소리 나는 대로 표기)

겹받침, 거센 연음, 비음화 구간은 실제 소리 나는 발음대로 적으면 발음이 선명해집니다(예: 빛나는 → 빈나는, 같이 걸을까 → 가치 걸을까, 꽃잎이 → 꼰니피, 닿을 듯 → 다을 듯). 영어 단어와 숫자는 알파벳·아라비아 숫자 대신 한글 발음으로 표기하세요(예: Love → 러브, 24시간 → 스물네 시간).

3. 구조 태그 및 호흡·장음 기호

가사 최상단에 [ko] 태그를 적고, [Intro], [Verse 1], [Pre-Chorus], [Chorus], [Bridge], [Outro] 같은 곡 구조 태그를 단독 줄로 배치하며 파트 사이에는 빈 줄을 한 줄씩 넣으세요. 연주·보컬 지시는 [Chorus - powerful], [Outro - fade out]처럼 간결한 영어 대괄호 태그로 표기하고, 소괄호 ( )는 실제로 부를 백보컬·화음 가사에만 사용하세요. 보컬이 숨을 쉬는 짧은 휴지기에는 쉼표(,), 음을 길게 끌어야 하는 단어 끝에는 하이픈(-)을 붙이세요.

처음 실행 준비

첫 실행 시 배경음악 → 한국어 번역 → 노래 순서로 필요한 실행 환경과 모델을 자동으로 준비합니다. 이미 준비된 항목은 건너뜁니다. Python이나 Git을 따로 설치할 필요가 없습니다. 인터넷 연결과 16GB 이상의 여유 공간을 확보해 주세요. 노래 모델만 약 8GB이며, 전체 다운로드는 인터넷 속도에 따라 오래 걸릴 수 있습니다. 준비가 끝나면 음악 생성과 번역은 내 컴퓨터에서 처리합니다.

소리숲 앱은 누구나 무료로 사용할 수 있습니다. 생성한 음악의 상업적 이용에는 선택한 AI 모델의 이용 조건이 적용됩니다.

배경음악의 Stable Audio는 매출 규모 등 라이선스 조건을 확인해야 합니다. 노래의 ACE-Step에도 해당 모델의 이용 조건이 적용됩니다.

소리숲 개인정보처리방침

소리숲은 개인정보를 수집하지 않으며, 음악을 만드는 데 입력한 내용과 생성 결과를 외부 서버로 전송하지 않습니다.

개인정보 수집과 외부 전송이 없습니다

소리숲은 회원가입이나 로그인이 필요 없으며, 개인정보를 수집하지 않습니다. 입력한 음악 설명·가사와 생성된 오디오를 외부 서버나 클라우드로 전송하지 않으며, 이용자를 추적하는 분석 도구를 사용하지 않습니다.

음악 생성은 내 컴퓨터 안에서

배경음악과 노래는 내 컴퓨터에서 직접 생성됩니다. 필요한 모델을 설치·다운로드한 뒤에는 인터넷 연결 없이도 생성할 수 있습니다. 기기 사양 정보는 내 컴퓨터에 맞는 설정을 추천하기 위해 기기 안에서만 사용됩니다.

기록과 음원도 내 컴퓨터에 보관

제목·음악 설명·가사·설정·생성 기록·음원은 내 컴퓨터에만 저장됩니다. 모델·실행 환경·다운로드 캐시는 앱이 설치된 드라이브의 SoriSoop Data 폴더에 저장됩니다. 이 폴더는 앱과 별도로 보관됩니다. 목록에서 삭제한 결과는 앱의 로컬 휴지통에 보관됩니다. 완전히 지우려면 휴지통의 파일도 삭제해 주세요. 앱을 삭제해도 로컬 데이터가 자동으로 지워지지는 않습니다.

모델 설치·다운로드와 앱 시작 시 GitHub 릴리즈 업데이트 확인에는 인터넷을 사용합니다. 업데이트 확인 시 GitHub에 접속하므로 IP 주소 등 일반적인 접속 정보가 전달될 수 있지만, 음악 설명·가사·음원·기기 사양은 전송하지 않습니다. 사용자가 직접 여는 AI 작사 도구나 PayPal 등의 외부 웹사이트에는 해당 서비스의 개인정보처리방침이 적용됩니다. 작사 요청문은 복사만으로 외부에 전송되지 않으며, 외부 AI에 직접 붙여넣어 제출하면 해당 서비스로 전달됩니다.
