음악 이용 조건

소리숲 앱은 누구나 무료로 사용할 수 있습니다. 생성한 음악의 상업적 이용에는 선택한 AI 모델의 이용 조건이 적용됩니다.

배경음악의 Stable Audio는 매출 규모 등 라이선스 조건을 확인해야 합니다. 노래의 ACE-Step에도 해당 모델의 이용 조건이 적용됩니다.

소리숲 개인정보처리방침

소리숲은 개인정보를 수집하지 않으며, 음악을 만드는 데 입력한 내용과 생성 결과를 외부 서버로 전송하지 않습니다.

개인정보 수집과 외부 전송이 없습니다

소리숲은 회원가입이나 로그인이 필요 없으며, 개인정보를 수집하지 않습니다. 입력한 음악 설명·가사와 생성된 오디오를 외부 서버나 클라우드로 전송하지 않으며, 이용자를 추적하는 분석 도구를 사용하지 않습니다.

음악 생성은 내 컴퓨터 안에서

배경음악과 노래는 내 컴퓨터에서 직접 생성됩니다. 필요한 모델을 설치·다운로드한 뒤에는 인터넷 연결 없이도 생성할 수 있습니다. 기기 사양 정보는 내 컴퓨터에 맞는 설정을 추천하기 위해 기기 안에서만 사용됩니다.

기록과 음원도 내 컴퓨터에 보관

제목·음악 설명·가사·설정·생성 기록·음원은 내 컴퓨터에만 저장됩니다. 모델·실행 환경·다운로드 캐시는 앱이 설치된 드라이브의 SoriSoop Data 폴더에 저장됩니다. 이 폴더는 앱과 별도로 보관됩니다. 목록에서 삭제한 결과는 앱의 로컬 휴지통에 보관됩니다. 완전히 지우려면 휴지통의 파일도 삭제해 주세요. 앱을 삭제해도 로컬 데이터가 자동으로 지워지지는 않습니다.

모델 설치·다운로드와 앱 시작 시 GitHub 릴리즈 업데이트 확인에는 인터넷을 사용합니다. 업데이트 확인 시 GitHub에 접속하므로 IP 주소 등 일반적인 접속 정보가 전달될 수 있지만, 음악 설명·가사·음원·기기 사양은 전송하지 않습니다. 사용자가 직접 여는 AI 작사 도구나 PayPal 등의 외부 웹사이트에는 해당 서비스의 개인정보처리방침이 적용됩니다. 작사 요청문은 복사만으로 외부에 전송되지 않으며, 외부 AI에 직접 붙여넣어 제출하면 해당 서비스로 전달됩니다.
