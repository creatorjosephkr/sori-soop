# 소리숲 (SoriSoop) v1.1.0 업데이트 내역

- **버전**: `v1.1.0`
- **작성일**: 2026-11-07

---

## 주요 업데이트 요약
- **성능/기능별 모델 추가**: 배경음악·노래·효과음 각 영역별 전체 가용 모델(`Small-Music`, `Medium`, `Small-SFX`, `ACE-Step 0.6B/1.7B`) 지원 및 원클릭 추가 설치 제공
- **효과음 생성 기능 추가**: 효과음 전용 제작 모드(**`효과음 만들기`**), 전용 프리셋, 1초 단위 길이 조절 및 **`효과음 목록`** 관리 기능 신설
- **네거티브 프롬프트 설정 추가**: 원치 않는 소리·음질 저하·발음 뭉개짐 등을 배제하는 **`네거티브 프롬프트`** 입력창 및 권장 기본값/복원 기능 제공
- **가사 누락/발음 부정확 개선**: ACE-Step 곡 기획 및 합성 파라미터 최적화, 한국어 발음(G2P)·음절 수 규칙 기반 작사 프롬프트 및 가이드 제공
- **UI 다듬기**: 입력·설정 레이아웃 간소화, 도움말 모달 전환, 목록 표시 개수 확대(10개), 기본 게인(`-8dB`) 조정 및 상태 알림 위치 개선
- **샘플 노래 생성 버튼 추가**: 왼쪽 사이드바에서 원클릭으로 한국어 시티팝 샘플 노래를 바로 생성해 볼 수 있는 기능 추가

---

## 상세 변경 내용

### 1. 성능/기능별 모델 추가
- **Stable Audio 3 전체 모델 라인업 지원**
  - **`Stable Audio 3 Small-Music` (가벼운 배경음악)**: 빠른 생성과 낮은 메모리 사용량을 제공하는 기본 배경음악 모델(최대 120초)
  - **`Stable Audio 3 Medium` (고품질 배경음악)**: 더 풍부한 악기 질감과 편곡 밀도를 제공하며 최대 **380초(약 6분 20초)** 생성을 지원하는 상위 모델 추가 (Apple Silicon `MLX` + `same-l` 디코더 / CPU `TFLite` + `same-s` 디코더 지원)
  - **`Stable Audio 3 Small-SFX` (효과음 전용)**: 음악이 아닌 효과음·환경음·폴리 사운드 합성에 특화된 전용 모델 추가
- **앱 내 선택형 모델 원클릭 추가 설치**
  - `Medium` 고품질 배경음악 모델이나 `Small-SFX` 효과음 모델을 처음 선택했을 때, 설정 화면 안에서 필요 용량을 확인하고 원클릭으로 다운로드·설치할 수 있는 안내 배너(`#sa3-install-notice`)와 실시간 설치 진행 표시를 추가했습니다.

### 2. 효과음 생성 기능 추가 (`효과음 만들기`)
- **효과음 전용 제작 모드 및 결과 목록 신설**
  - 상단 제작 탭에 **`효과음 만들기`** 탭을 추가하여 배경음악·노래와 분리된 효과음 전용 작업 공간을 구성했습니다.
  - 우측 생성 결과 영역에 **`효과음 목록`** 탭을 추가하여 생성된 효과음을 별도로 모아 듣고 재생·제목 수정·WAV 다운로드·삭제할 수 있습니다.
- **초단위(1~120초) 효과음 길이 설정**
  - 짧은 효과음부터 긴 환경음(Ambience)까지 만들 수 있도록 길이 조절 범위를 **1초~120초**(초기 권장값 **5초**)로 지원합니다.
- **효과음 전용 스타일 프리셋 및 빠른 선택 태그 제공**
  - 효과음 모드 전환 시 프리셋 영역이 **`효과음 스타일 프리셋`**으로 자동 전환됩니다.
  - **빠른 선택 버튼**: `자연/날씨`, `일상/폴리`, `SF/기계음`
  - **효과음 종류 프리셋**: 자연/날씨 환경음, 일상/실내 폴리 효과음, 발자국/움직임 소리, UI/알림/버튼음, 타격/충돌/시네마틱 임팩트, SF/사이버/기계음, 미스터리/긴장감 효과음
  - **공간감 및 녹음 질감 프리셋**: 가깝고 선명하게(무향/클로즈업), 자연스러운 실내 공간, 넓고 울림 있는 공간, 탁 트인 야외 공간
  - 한글로 효과음 설명을 입력하면 내 컴퓨터의 로컬 번역 모델을 통해 영어로 자동 변환한 뒤 음악·보컬 성분을 배제한 순수 효과음 조건으로 합성합니다.

### 3. 가사 누락 및 발음 부정확 현상 개선
- **ACE-Step 곡 구성(Planner LM) 및 오디오 합성(DiT) 파라미터 최적화**
  - `5Hz LM` 곡 구성 단계에 가사·언어·메타데이터 조건 반영도를 높이는 가이던스 설정(`temperature=0.85`, `cfg_scale=2.0`, `top_p=0.9`)을 적용했습니다.
  - `acestep-v15-turbo` 오디오 합성 단계에 업스트림 권장 타임스텝 시프트(`shift=3.0`)를 명시하여 보컬 발음 아티팩트와 박자 밀림을 줄였습니다.
- **AI 작사 요청 프롬프트 고도화 (`작사 요청문 복사`)**
  - 한 줄당 공백 제외 **6~10음절(최대 12음절 이내)** 제한으로 가사 누락을 방지하도록 규칙을 강화했습니다.
  - 겹받침·연음·비음화 구간을 실제 소리 나는 대로 적는 **한국어 발음 최적화(G2P 표기)** 규칙과 영어·숫자의 한글 발음 표기 규칙을 반영했습니다.
  - `[ko]` 언어 태그, 파트별 구조 태그(`[Intro]`, `[Verse 1]`, `[Pre-Chorus]`, `[Chorus]` 등), 호흡 기호(`,`), 장음 기호(`-`), 영문 스타일 프롬프트(`BPM` 포함) 출력 형식을 체계화했습니다.
- **`ACE-Step 가사 생성 가이드` 모달 추가**
  - 가사 입력창 아래에 `가사 생성 가이드` 버튼을 배치하여, 앱 안에서도 언제든 음절 수·소리 나는 대로 표기·구조 태그 작성법을 확인할 수 있도록 개선했습니다.

### 4. UI 다듬기 및 기본 설정 개선
- **생성 결과 목록 표시 확대 및 알림 위치 개선**
  - 생성 결과 목록을 한 페이지에 최대 **10개**까지 표시하도록 확대했습니다(기존 4개).
  - 생성 시작 안내(`'생성을 시작했습니다. 다른 작업은 완료 후 시작할 수 있습니다.'`)와 삭제 완료 안내(`'결과를 삭제했습니다. 파일은 로컬 휴지통에 보관됩니다.'`)가 생성 결과 목록 상단에 명확히 표시되도록 이동했습니다.
- **입력창 및 도움말 레이아웃 정리**
  - 가사 입력창(`#lyrics`)의 기본 세로 높이를 기존 대비 **1.5배(`225px`)** 확대했습니다.
  - 음악/노래/효과음 설명 입력칸 아래의 긴 안내 문구를 숨기고, 입력칸 왼쪽 아래의 느낌표(`!`) 아이콘 버튼을 눌렀을 때 작은 모달창으로 안내를 띄우도록 변경했습니다.
  - 보컬 언어 선택칸 아래의 중복 안내 문구와 설정 저장 버튼 위의 경고 문구를 제거하여 화면을 깔끔하게 정리했습니다.
- **생성 설정 컨트롤 한 줄 배치 및 기본 게인 조정**
  - **최대 게인(출력 피크 상한)** 기본값을 **`-8dB`**로 설정하고, 라벨과 입력칸을 한 줄에 배치했습니다.
  - **음악 길이** 라벨과 초 단위 숫자 입력칸을 한 줄에 배치하고(슬라이더 위치·스타일 유지), 불필요한 하단 설명 문구와 초기 권장 길이·실측 안내 박스를 제거했습니다.
  - 왼쪽 사이드바의 시작 안내 문구를 오해 없이 명확한 표현(`"짧은 길이로 먼저 만들어 보면 기기의 부담을 줄일 수 있어요. 내 컴퓨터의 처리 속도를 확인한 뒤 원하는 길이로 설정해 보세요."`)으로 다듬었습니다.
  - 왼쪽 사이드바 `내 컴퓨터 진단`의 `시스템` 항목이 커널 이름(`Darwin`) 대신 실제 운영체제 이름과 버전(예: `macOS 27.0.1`, `Windows 11`)으로 표시되도록 개선했습니다.

### 5. 샘플 노래 생성 버튼 추가
- 왼쪽 사이드바(`성능 측정 · 20초 배경음악` 버튼 아래)에 **`샘플 노래 만들기`** 버튼을 추가했습니다.
- 버튼을 클릭하면 한국어 시티팝 스타일 프롬프트(`108 BPM`)와 발음 최적화가 적용된 샘플 한국어 가사, 자동 길이 설정이 자동으로 입력되면서 즉시 샘플 보컬 노래 생성이 시작됩니다.

### 6. 네거티브 프롬프트 설정 기능 추가
- **배경음악·노래·효과음 전 모드 네거티브 프롬프트 지원**
  - 음악/효과음 설명 입력칸 아래에 제외할 소리나 품질 문제를 지정할 수 있는 **`네거티브 프롬프트`** 입력창(`#negative-prompt`, 최대 1,000자)과 **`기본값 복원`** 버튼을 추가했습니다.
  - `Stable Audio 3` (`Small-Music`, `Medium`, `Small-SFX`) 생성 시 `--negative-prompt` 및 가이던스(`--cfg 2.0`)로 전달되며, `ACE-Step 1.5` 보컬 노래 생성 시 `5Hz LM` 곡 구성 플래너와 생성 파라미터(`negative_prompt` / `lm_negative_prompt`)에 직접 반영됩니다.
  - 한글로 네거티브 프롬프트를 입력한 경우에도 내 컴퓨터의 로컬 번역 모델을 통해 영어로 자동 변환하여 적용합니다.
- **음질·믹싱·발음 보정용 권장 기본값 적용**
  - 기본 네거티브 프롬프트:
    `low quality, muddy mix, clipping, distortion, harsh high frequencies, out of tune, arrhythmia, sudden silence, background noise, hiss, hum, muffled audio, robotic voice, slurred pronunciation, gibberish, abrupt cut`
