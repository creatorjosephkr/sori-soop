# 소리숲 (SoriSoop) v1.1.2 업데이트 내역

- **버전**: `v1.1.2`
- **작성일**: 2026-11-09

---

## 주요 업데이트 요약
- **새 버전 다운로드 시 릴리즈 페이지 이동 및 앱 자동 종료 지원**: 업데이트 알림 창에서 '새 버전 다운로드' 선택 시 최신 릴리즈 페이지를 기본 웹브라우저로 열고 앱을 안전하게 종료하여, 파일 잠금 문제 없이 즉시 새 버전을 교체·설치할 수 있도록 개선

---

## 상세 변경 내용

### 1. 새 버전 다운로드 버튼 동작 개선
- **최신 릴리즈 페이지 연결**
  - 기존의 백그라운드 단일 바이너리 직접 다운로드 방식 대신, 플랫폼별 배포 파일(`dmg`, `setup.exe`) 및 체크섬(`SHA256SUMS.txt`), 릴리즈 노트를 직접 확인하고 선택할 수 있도록 공식 최신 릴리즈 페이지(`releaseUrl`)를 기본 브라우저에서 열도록 변경했습니다.
- **앱 프로세스 자동 종료 연동**
  - 다운로드 버튼 클릭 시 브라우저가 호출된 후 0.6초 뒤에 세션과 엔진을 안전하게 정리하고 네이티브 창을 닫아 앱이 자동 종료됩니다.
  - Windows의 Inno Setup 설치 프로그램 실행 시 실행 파일(`SoriSoop.exe`) 잠금으로 인한 설치 차단이나 오류를 미연에 방지합니다.

### 2. UI 및 테스트 보강
- 앱 닫기 없이 릴리즈 소식만 확인하고자 하는 사용자를 위해 'GitHub 릴리즈 보기' 버튼은 기존대로 앱을 유지한 채 페이지만 열 수 있도록 유지했습니다.
- 릴리즈 URL 이동 및 종료 스케줄 호출 동작을 검증하는 HTTP 테스트 케이스를 갱신했습니다.
