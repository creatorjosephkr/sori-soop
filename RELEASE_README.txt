Mac: DMG를 열고 앱을 설치할 드라이브의 폴더로 SoriSoop.app을 복사한 뒤 실행하세요.
Apple Silicon / macOS 14 이상을 대상으로 합니다.
Windows: SoriSoop-1.3.0-windows-x64-setup.exe를 실행하고 화면 안내에 따라 설치하세요.
Windows 10 버전 2004 이상 또는 Windows 11의 x64 PC가 필요합니다.
Python을 포함한 앱과 바로가기를 설치하고, 필요한 경우 WebView2와 Visual C++ 실행 도구를 함께 설치합니다.
Windows 권한 요청이 나타나면 허용해 주세요. 폴더 복사나 별도 도구 다운로드는 필요하지 않습니다.

[Windows 11 설치 시 참고]
- "Microsoft에서 확인한 앱이 아닙니다" 알림이 뜨는 경우 [그래도 설치]를 누르거나, Windows 설정 > 앱 > 고급 앱 설정 > 앱을 설치할 위치 선택을 '제한 없음' 또는 '어디서나'로 변경하세요.
- "Windows의 PC 보호(SmartScreen)" 창이 나타나면 [추가 정보]를 누른 뒤 [실행]을 클릭하세요.

첫 실행 시 별도 모달창에서 배경음악·한국어 번역·노래 기능을 자동으로 준비합니다.
Python·Git·음악 생성 패키지를 사용자가 따로 설치할 필요가 없습니다.
모델 준비에는 인터넷과 16GB 이상의 여유 공간이 필요합니다.
노래 모델만 약 8GB이며, 인터넷 속도에 따라 준비 시간이 달라집니다.
모델 준비 후 음악 설명·가사·음원은 내 컴퓨터에서 처리합니다.
[1.3.0 주요 변경]
- 노래 만들기에서 보컬 노래와 가사 없는 Instrumental 연주곡을 선택할 수 있습니다.
- 보컬 노래·연주곡·배경음악·효과음의 제목과 음악 설명을 따로 유지합니다.
- 배경음악과 연주곡에서 BPM을 선택하거나 직접 입력할 수 있습니다.
- 네거티브 프롬프트를 항목별 설명이 있는 체크박스로 선택합니다.
- 노래와 연주곡 결과를 구분하고 만들기 유형을 선택하면 해당 목록도 함께 엽니다.
- 결과 목록의 휴지통 버튼으로 삭제 항목을 조회하고 종류별 또는 전체 휴지통을 비울 수 있습니다.
- 휴지통 비우기는 영구 삭제이며 복구할 수 없습니다. 기존 휴지통은 자동으로 비워지지 않습니다.

음악·노래·효과음 결과에서 WAV와 MP3를 다운로드할 수 있습니다.
MP3는 처음 다운로드할 때 내 컴퓨터에서 변환하며 별도 프로그램 설치가 필요하지 않습니다.
Windows 노래 생성은 NVIDIA GPU(VRAM 6GB 이상) 감지 시 CUDA 12.8 실행 환경을 준비합니다.
GPU 실행 검사에 실패하면 설치 로그에 오류를 표시합니다. NVIDIA 드라이버 업데이트 후 다시 준비하세요.
NVIDIA GPU가 없거나 CPU 실행 방식을 선택한 경우 노래 생성은 오래 걸릴 수 있습니다.

이 배포본에는 Apple Developer ID 공증 또는 Windows Authenticode 서명이 없습니다.
운영체제에서 출처 확인 안내가 표시될 수 있습니다.

모델·실행 환경·다운로드 캐시는 앱 설치 위치의 SoriSoop Data 폴더에 저장합니다.
음악·설정·기록·로그는 사용자 홈의 .local-music-studio 폴더에 보관합니다.
앱을 제거해도 모델과 사용자 데이터는 남습니다. 필요할 때 별도로 백업·삭제하세요.
모델·Microsoft 구성요소에는 개별 이용 조건이 적용됩니다. THIRD_PARTY_NOTICES.txt를 확인해 주세요.

후원과 개인정보처리방침은 앱 왼쪽 사이드바 하단에서 확인할 수 있습니다.
