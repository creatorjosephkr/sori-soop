Mac: DMG를 열고 앱을 설치할 드라이브의 폴더로 SoriSoop.app을 복사한 뒤 실행하세요.
Apple Silicon / macOS 14 이상을 대상으로 합니다.
Windows: SoriSoop-1.0.0-windows-x64-setup.exe를 실행하고 화면 안내에 따라 설치하세요.
Windows 10 버전 2004 이상 또는 Windows 11의 x64 PC가 필요합니다.
앱과 바로가기를 설치하고, 필요한 경우 WebView2와 Visual C++ 실행 도구를 함께 설치합니다.
Windows 권한 요청이 나타나면 허용해 주세요. 폴더 복사나 별도 도구 다운로드는 필요하지 않습니다.

첫 실행 시 별도 모달창에서 배경음악·한국어 번역·노래 기능을 자동으로 준비합니다.
Python·Git·음악 생성 패키지를 사용자가 따로 설치할 필요가 없습니다.
모델 준비에는 인터넷과 16GB 이상의 여유 공간이 필요합니다.
노래 모델만 약 8GB이며, 인터넷 속도에 따라 준비 시간이 달라집니다.
모델 준비 후 음악 설명·가사·음원은 내 컴퓨터에서 처리합니다.
Windows는 CPU 실행 방식입니다. 구형 GPU에 의존하지 않으며 노래 생성은 느릴 수 있습니다.

이 배포본에는 Apple Developer ID 공증 또는 Windows Authenticode 서명이 없습니다.
운영체제에서 출처 확인 안내가 표시될 수 있습니다.

모델·실행 환경·다운로드 캐시는 앱 설치 위치의 SoriSoop Data 폴더에 저장합니다.
음악·설정·기록·로그는 사용자 홈의 .local-music-studio 폴더에 보관합니다.
앱을 제거해도 모델과 사용자 데이터는 남습니다. 필요할 때 별도로 백업·삭제하세요.
모델·Microsoft 구성요소에는 개별 이용 조건이 적용됩니다. THIRD_PARTY_NOTICES.txt를 확인해 주세요.

후원과 개인정보처리방침은 앱 왼쪽 사이드바 하단에서 확인할 수 있습니다.
