Mac: DMG를 열고 SoriSoop.app을 Applications로 복사한 뒤 실행하세요.
Apple Silicon / macOS 14 이상을 대상으로 합니다.
Windows: ZIP 전체를 압축 해제한 뒤 SoriSoop.exe를 실행하세요.
Windows 10/11 x64, Microsoft Edge WebView2 Runtime이 필요합니다.
WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

첫 실행 화면에서 사용할 기능의 '준비' 버튼을 눌러 주세요.
Python·Git을 따로 설치할 필요가 없습니다. 모델 준비에 인터넷을 사용합니다.
배경음악 모델은 첫 생성 시 추가 다운로드하며, 노래 모델은 약 8GB입니다.
노래 준비에는 16GB 이상, 나머지 기능 준비에는 3GB 이상의 여유 공간을 확보해 주세요.
모델 준비 후 음악 설명·가사·음원은 내 컴퓨터에서 처리합니다.
Windows 1.0.1은 CPU 실행 방식입니다. 구형 GPU에 의존하지 않으며 노래 생성은 느릴 수 있습니다.

이 배포본에는 Apple Developer ID 공증 또는 Windows Authenticode 서명이 없습니다.
운영체제에서 출처 확인 안내가 표시될 수 있습니다.

설정·음악·모델·로그는 사용자 홈의 .local-music-studio 폴더에 저장합니다.
앱 파일을 삭제해도 이 데이터는 남습니다. 필요할 때 별도로 백업·삭제하세요.
모델은 별도 이용 조건을 따릅니다. THIRD_PARTY_NOTICES.txt를 확인해 주세요.

후원과 개인정보처리방침은 앱 왼쪽 사이드바 하단에서 확인할 수 있습니다.
