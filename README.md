# 소리숲 · Local Music Studio

앱 버전: 1.0.1 (`VERSION`, 앱 메타데이터 및 사이드바 이름 옆에 표시).


## 다운로드 및 실행

[최신 릴리즈 다운로드](https://github.com/creatorjosephkr/sori-soop/releases/latest)

- Apple Silicon Mac(macOS 14 이상): `macos-arm64.dmg`를 열고 `SoriSoop.app`을 Applications에 복사합니다.
- Windows 10/11 x64: `windows-x64.zip` 전체를 압축 해제한 뒤 `SoriSoop.exe`를 실행합니다. Microsoft Edge WebView2 Runtime이 필요합니다.
- 첫 실행 화면에서 사용할 기능의 ‘준비’ 버튼을 누릅니다. 배포용 앱은 Python·Git을 별도로 설치할 필요가 없습니다. 모델 준비와 최초 모델 다운로드에는 인터넷을 사용합니다.
- Windows 1.0.1은 CPU 실행 경로입니다. 구형 GPU에 의존하지 않으며 노래 생성은 오래 걸릴 수 있습니다. Windows에서의 노래 생성 성능과 다양한 GPU 조합은 별도 검증 대상입니다.
- 현재 배포본은 Developer ID 공증/Authenticode 서명이 없습니다. 운영체제의 출처 확인 안내가 표시될 수 있습니다.

앱과 모델은 별도 라이선스를 따릅니다. 앱 소스는 [MIT](LICENSE), 모델 및 폰트·실행 구성요소는 [개별 이용 조건](THIRD_PARTY_NOTICES.txt)을 확인하세요. Stable Audio 모델은 Stability AI Community License의 조건을 따르므로 앱의 MIT 라이선스가 모델 이용 조건을 대체하지 않습니다.

앱 파일과 모델을 분리했습니다. 앱을 업데이트해도 설정·음원·모델은 사용자 홈의 `.local-music-studio/`에 유지됩니다. 앱 삭제만으로 이 폴더가 자동 삭제되지는 않습니다.

## 소스 코드로 실행

로컬 PC에서 배경음악과 가사 기반 보컬 노래를 생성하는 앱입니다. 앱 서버는 Python 3.11 이상으로 실행하며, 생성 모델은 별도의 실행 환경을 사용합니다.

```sh
python3 app.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 종료는 Ctrl+C 입니다.

## 기능

- 운영체제·칩·메모리·NVIDIA 장치·저장 공간 진단
- 사양 기반 모델·길이 추천, 자동 / 추천값 고정 / 직접 설정
- 배경음악: Stable Audio 3 Small-Music, 최대 120초
- 보컬 노래: ACE-Step 1.5 Turbo + 0.6B 곡 구성 모델, 한국어·영어·일본어·중국어·기타 언어 선택
- 가사 예시 입력, 가사·언어·시드·설정·모델 버전 보관
- 생성 상태·단계·경과 시간, 취소, 실패 시 오류 상세 확인
- 결과를 배경음악 / 보컬 노래 탭으로 분류, 재생 / WAV 다운로드 / 삭제
- 선택 사항인 제목 입력(100자 이내), 결과 목록과 다운로드 파일명에 반영
- 실제 오디오에 반응하는 디지털 주파수 막대 / 아날로그 파형, 표시 끄기 선택
- 동일한 모델·실행 방식·길이의 성공 기록으로 실제 처리 시간 범위 표시

음악 생성은 한 번에 하나만 실행합니다. 수동 설정을 자동 진단이 덮어쓰지 않습니다. 노래 기본 추천 길이는 30초입니다. 결과 길이의 모델 상한과 기기 권장 길이는 서로 다릅니다.

## 모델 설치

소스 실행 환경 준비에는 `uv`가 필요합니다. Git 설치 없이 고정된 실행 코드 아카이브를 다운로드합니다. 설치 시 인터넷을 사용하고 가중치는 추가 저장 공간을 사용합니다. 코드 라이선스와 모델·구성요소 약관은 구분하여 공식 모델 카드에서 확인하세요.

배경음악 실행 환경:

```sh
python3 setup_engine.py
```

모델은 첫 생성 시 다운로드합니다. Apple Silicon에서는 MLX 경로를 사용합니다. 모델 약 1.8GB와 실행 패키지 공간이 필요합니다.

보컬 노래 실행 환경 및 모델:

```sh
python3 setup_song.py
```

노래 모델 가중치는 약 7.6GB입니다. 가사 기반으로 곡 구성을 먼저 준비하고 계획 모델을 해제한 뒤 음악을 생성하여 두 모델의 동시 적재를 피합니다. 사용자가 입력한 가사를 사용하며 자동 작사는 제공하지 않습니다. Apple Silicon의 DiT는 BF16 MPS, 오디오 변환은 native MLX를 사용합니다. FP16에서는 비유한 계산값이 발생하여 사용하지 않습니다. CPU 경로는 FP32입니다.

`engines-version.txt`, `song-engine-version.txt`는 사용한 코드 커밋이며, 노래 가중치 및 계획 모델 버전은 `song-model-version.txt`, `song-planner-version.txt`에 기록합니다. 설치된 실행 환경 버전은 `requirements-mlx.lock`, `requirements-song-mac.lock`으로 고정합니다.

## 로컬 한영 번역 설치

```sh
python3 setup_translation.py
```

Helsinki-NLP의 `opus-mt-ko-en`을 고정된 리비전(`translation-model-version.txt`)으로 다운로드하고, CTranslate2 INT8 모델로 변환합니다. 변환된 모델은 약 79MiB이며 `engines/translation/model/`에 저장합니다. 변환 준비에는 CPU PyTorch가 필요하고 실행 시에는 CTranslate2·SentencePiece만 사용합니다. 설치·다운로드만 인터넷을 사용하며 번역 실행은 오프라인입니다. 설치되지 않은 환경에서는 한국어 설명의 생성을 막고 영어 설명 또는 번역 모델 설치를 안내합니다.

번역은 음악 모델보다 먼저 별도 프로세스에서 실행하고 종료하여 동시 적재하지 않습니다. 긴 설명은 나눠 번역하며 조용히 잘라내지 않습니다. 번역 결과가 입력 상한을 넘으면 설명을 줄이도록 안내하고 생성을 중단합니다. 번역 실패 시 한글을 그대로 모델에 전달하지 않습니다. 취소는 번역 단계에서도 적용합니다. 번역 결과·모델 리비전·번역 로그는 로컬 작업 기록에 저장하고 결과 삭제 시 함께 로컬 휴지통으로 옮깁니다.

- 모델 출처: https://huggingface.co/Helsinki-NLP/opus-mt-ko-en (모델 카드: Apache-2.0)
- 실행기: https://opennmt.net/CTranslate2/guides/transformers.html
- M4 16GB의 짧은 예시 번역 1회: 약 0.21초, 번역 프로세스 최대 RSS 약 192MiB. 환경·입력 길이에 따라 달라집니다.

## 사용

음악 길이는 숫자 입력과 슬라이더를 모두 지원하며 1초 단위로 서로 동기화됩니다. 배경음악은 10~120초, 노래는 10~600초 범위이며 모델의 상한에 맞춰 입력 범위를 바꿉니다. 자동 설정에서도 직접 입력한 길이를 사용합니다. 입력 중인 빈 값·범위 초과·소수는 안내를 표시하고 생성 및 설정 저장을 막으며, 주기적인 작업 조회가 입력값을 덮어쓰지 않습니다.

배경음악 또는 보컬 노래 선택 → 장르·분위기 설명 → 노래는 가사와 언어 입력 → 음악 생성 → 오른쪽 결과에서 재생·다운로드.

제목은 선택 사항입니다. 입력하면 결과 목록과 WAV 다운로드 이름에 사용하고 음악 설명은 펼친 상세 영역에서 확인합니다. 기존 결과를 펼친 뒤 ‘제목 수정’으로 1~100자의 제목을 저장할 수 있습니다. 수정은 재생을 중단하지 않으며 원본 음악·가사·설정을 유지하고 목록과 다운로드 이름에 반영합니다. 새로고침하면 제목·음악 설명·가사는 초기화되며 저장된 결과는 유지됩니다. 제목 없이 생성하면 배경음악 / 보컬 노래로 표시하며, 제목 기능 도입 이전 기록은 기존 설명을 표시합니다.

재생 영역에서 디지털·아날로그·끄기를 선택할 수 있으며 마지막 선택은 브라우저에 저장됩니다. 디지털은 실제 주파수 크기, 아날로그는 실제 오디오 파형을 표시합니다. 재생 위치·음량·음소거를 조절할 수 있고 표시 방식은 재생 중에도 전환됩니다. 스펙트럼 분석은 출력 음량을 증폭하지 않으며 오디오 파일을 변경하지 않습니다. 일시정지·닫힌 결과·숨겨진 탭에서는 애니메이션을 멈추고 운영체제의 움직임 줄이기 설정을 따릅니다.

한글 음악 설명은 내 컴퓨터에서 영어로 자동 번역한 뒤 생성 모델에 전달합니다. 제목과 가사는 번역하지 않습니다. 영어만 쓴 설명과 영어로 된 프리셋 구간은 그대로 사용하며, 원문과 실제 생성에 사용한 영어 설명은 결과에 함께 보관합니다. 번역문은 결과를 펼쳐 ‘생성에 사용한 영어 설명’에서 확인할 수 있습니다. 자동 번역이 의도와 다르면 설명을 간단히 쓰거나 영어로 직접 수정할 수 있습니다. 노래는 설명 512자, 가사 4000자 이내입니다. 짧은 시간에 긴 가사를 넣으면 모두 반영되지 않을 수 있습니다. 발음과 원문 반영 정도는 생성 결과별로 확인해야 합니다.

## 데이터와 실행

사이드바의 ‘개인정보처리방침’은 후원 아이콘 위에 표시합니다. 안내 모달에는 개인정보 수집 및 생성 입력·결과의 외부 전송 없음, 로컬 생성, 로컬 기록·휴지통 보관, 모델 다운로드와 사용자가 직접 이용하는 외부 서비스의 구분을 명시합니다. 확인·닫기·Esc·바깥 영역 클릭으로 닫을 수 있으며 작은 화면에서는 모달 내부를 스크롤합니다.

사이드바 하단의 ‘소리숲 후원하기’를 누르면 카카오뱅크 QR 코드와 PayPal 이미지를 표시합니다. 이미지 원본은 프로젝트의 `spon/` 폴더에 보관합니다. PayPal 클릭은 앱 서버에서 운영체제의 기본 브라우저(macOS `open`, Windows `startfile`, Linux `xdg-open`)로 지정된 PayPal.Me 후원 링크를 엽니다. 모달은 닫기 버튼·Esc·바깥 영역 클릭으로 닫히며 키보드 포커스가 후원 버튼으로 돌아옵니다.

- 기본 데이터 위치: `~/.local-music-studio/`
- `settings.json`: 사용자 설정
- `jobs/`: 작업 기록·로그·진행 단계·곡 구성 자료
- `audio/`: 완성 WAV
- `trash/`: 목록에서 삭제한 결과의 파일과 기록
- `LOCAL_MUSIC_DATA`: 저장 폴더 변경, `PORT`: 포트 변경

서버는 `127.0.0.1`에만 바인딩합니다. 가사와 오디오를 외부 서비스로 보내지 않습니다. 노래 생성 프로세스는 로컬 모델만 사용하도록 오프라인 모드로 실행합니다. 모델은 생성 프로세스 종료 시 해제합니다. 앱 종료로 중단된 기록은 다시 실행하면 중단으로 표시됩니다.

## 검증 및 한계

2026-11-06, Apple M4 / 통합 메모리 16GB에서 검증:

- 배경음악 20초·60초 실제 생성, WAV 재생·다운로드 경로 확인. 모델 준비 후 60초 생성은 앱 기준 약 4.36초.
- 보컬 노래 30초 실제 생성, 한국어 가사·언어·시드 보관, 48kHz 스테레오 WAV와 요청 길이 확인.
- 계획 모델을 포함한 30초 노래 생성은 한 차례 약 75초. 준비·현재 부하·설정에 따라 변동합니다.
- 사용자 청취에서 보컬과 가사가 들리는 것을 확인했습니다. 음악 음성 인식의 성공 여부를 음질 판정 기준으로 사용하지 않습니다.
- 단위·작업 생명주기·HTTP 테스트: `python3 -m unittest discover -s tests`.

M1 8GB와 Windows/구형 GPU의 실제 성능은 별도 검증 대상입니다. CPU 기반 노래 생성은 느릴 수 있습니다. 소요 시간 측정값은 해당 기기·설정의 관측값으로, 다른 길이나 기기의 성능을 보장하지 않습니다. 프로세스 RSS와 MLX 엔진 최고 메모리는 서로 다른 지표이며 전체 시스템·그래픽 메모리 사용량을 뜻하지 않습니다. MP3 변환, 자동 작사, 모델 설치 UI는 아직 제공하지 않습니다.

## 출력 레벨과 생성 중 표시

최대 게인 설정은 디지털 출력 샘플의 피크 상한(dBFS)이며, 기본 -6dB, 설정 범위 -24~0dB입니다. 최대 게인과 선택한 길이는 자동 설정에서도 직접 변경할 수 있고 설정 저장 시 유지됩니다. 모델의 원본 부동소수점 오디오를 PCM으로 변환하기 전에 한 곡 전체에 일정한 감쇠를 적용합니다. 상한보다 작은 음원은 키우지 않으며, 스테레오 채널 간 비율도 유지합니다. 실제 저장 파일의 피크를 검사하고 생성 기록에 저장합니다. 기존 파일은 변경하지 않습니다. 모델 자체에 포함된 왜곡을 복원하는 기능은 아닙니다.

생성 중 안내에는 움직이는 홀로그램 배경을 표시하고 완료·실패·취소 시 해제합니다. 움직임 줄이기 설정에서는 애니메이션을 끕니다. 아이콘과 효과는 로컬 파일/CSS만 사용합니다.

## 작업 화면과 결과 페이지

생성 입력과 결과 목록은 40:60 비율로 나누고 세로 구분선만 사용합니다. 결과 영역은 독립 스크롤이나 고정 위치를 사용하지 않고 문서 전체와 함께 스크롤됩니다. 좁은 화면에서는 두 영역을 세로로 배치합니다. 결과는 종류별로 한 페이지에 5개씩 표시하며 페이지 번호와 이전/다음 버튼으로 이동합니다. 탭별 페이지를 유지하고 마지막 페이지 항목 삭제 시 유효한 페이지로 보정합니다. 기존 100개 조회 제한을 제거하여 오래된 기록도 페이지로 조회할 수 있습니다.

입력 탭은 ‘배경음악 만들기 / 노래 만들기’, 결과 탭은 ‘배경음악 목록 / 노래 목록’으로 표시합니다. 생성 버튼 옆의 ‘새로 만들기’는 제목·음악 설명·가사·프리셋 선택과 작사 요청문을 초기화하고 제목 입력란으로 이동합니다. 생성 설정과 기존 결과는 유지하며 진행 중인 작업을 취소하지 않습니다. 사이드바의 음악 만들기·보관함 메뉴는 제거했습니다. UI 아이콘은 공통 SVG(`web/icons.js`)를 사용하며 신규 아이콘도 SVG로 추가합니다.

## 음악 스타일 프리셋

앱 폰트는 Noto Sans KR(Korean) 가변 폰트입니다. Google Fonts 공식 배포본을 `web/fonts/`에 포함하며 외부 폰트 서버에 접속하지 않습니다. 굵기 100~900을 지원하고 입력란·버튼에도 적용합니다. 출처·파일 해시는 `web/fonts/SOURCE.txt`, SIL Open Font License는 `web/fonts/OFL-NotoSansKR.txt`에 보관합니다.

음악 설명 아래에서 장르·보컬 음색·감정·템포·창법을 조합해 선택할 수 있습니다. 33개 항목을 제공하며 기존에 직접 쓴 설명은 유지하고 선택한 영어 설명을 추가합니다. 같은 항목을 다시 선택하면 이전 프리셋 문구만 교체합니다. 템포와 창법은 별도 항목으로 동시에 선택할 수 있습니다. 배경음악에서는 보컬·창법 항목을 숨기고 연주용 설명과 보컬 제외 조건을 사용합니다. 프리셋 선택 해제는 직접 입력한 문구를 지우지 않습니다. 노래 설명의 512자 한도를 넘는 조합은 추가하지 않으며, 새로고침하면 설명과 선택값을 함께 초기화합니다.

## 앱 빌드

macOS와 Windows 각각의 운영체제에서 Python 3.11로 실행합니다.

```sh
python -m pip install -r requirements-build.txt
python scripts/build_desktop.py
```

`artifacts/`에 macOS DMG 또는 Windows ZIP과 SHA-256 체크섬을 만듭니다. 모델·가중치·개인 생성 기록은 빌드에 포함하지 않습니다. `desktop.py --self-test`는 패키지 리소스·로컬 서버·설치 도구를, `--smoke-ui`는 숨겨진 네이티브 창의 실제 로딩을 확인합니다.

GitHub Actions의 Desktop release를 수동 실행하거나 `v*` 태그를 푸시하면 두 운영체제의 테스트·빌드·패키지 검사를 실행한 뒤 릴리즈 초안에 파일을 첨부합니다. 모든 플랫폼이 통과한 초안을 확인한 후 공개합니다. 일반 CI에는 모델을 다운로드하지 않으며 릴리즈 빌드에서 별도의 생성 검증을 수행합니다.

1.0.1부터 기본 연결 주소가 사용 중이면 빈 주소를 자동으로 선택하고, 같은 데이터 폴더의 기존 소리숲 서버는 확인 후 재사용합니다. 데이터 폴더 잠금으로 서버 중복 실행에 따른 생성·기록 충돌을 방지합니다. 배포 패키지 검사는 주소가 이미 점유된 상태에서도 서버와 네이티브 창이 열리는지 확인합니다.
