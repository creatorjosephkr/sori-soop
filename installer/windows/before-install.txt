소리숲을 설치합니다.

설치 위치를 선택하면 Python 실행 환경을 포함한 앱과 바로가기를 자동으로 설치합니다.
앱에 필요한 Microsoft WebView2와 Visual C++ 실행 도구도 포함되어 있으며, 필요한 경우 자동으로 설치합니다.
Windows 권한 허용 창이 나타나면 허용해 주세요. Microsoft 구성요소에는 Microsoft 이용 조건이 적용됩니다.

설치 완료 후 바탕화면 또는 시작 메뉴에서 소리숲을 실행해 주세요.
Python이나 Git을 따로 설치하거나 명령어를 입력할 필요가 없습니다.
첫 실행 시 안내 창에서 음악 생성 프로그램과 모델을 자동으로 준비합니다.
이 과정에는 인터넷과 16GB 이상의 여유 공간이 필요합니다.

추가 드라이브에 설치해도 모델과 실행 환경은 해당 설치 위치의 SoriSoop Data 폴더를 사용합니다.
음원·설정·기록은 사용자 데이터 폴더에 보관됩니다.
앱을 제거해도 모델·음원·설정·기록은 자동 삭제하지 않습니다.
