소리숲 2.0.0은 작업 목적과 숙련도에 맞춘 **기본(Simple) / 고급(Advanced) 화면 모드**, **화이트 · 라이트그레이 · 다크그레이 3종 색상 테마**, 그리고 내 컴퓨터에서 직접 보컬 참조 음성을 만들고 디자인할 수 있는 **Qwen3-TTS 보컬 음성 생성기(0.6B 기본 성우 · 1.7B 새 음색 디자인)**를 새롭게 도입한 메이저 업데이트입니다.

## 새로운 기능

### 1. 기본(Simple) · 고급(Advanced) 2단계 작업 화면 및 3종 테마
- **화면 모드 전환**: 상단 바에서 초보자도 바로 음악을 만들 수 있는 **기본 · Simple** 모드와 세부 엔진·샘플러·창작 제어 파라미터를 조절하는 **고급 · Advanced** 모드를 즉시 전환할 수 있습니다.
- **3종 색상 테마 지원**: **화이트**, **라이트그레이**, **다크그레이(다크모드)** 테마를 지원하며 선택한 모드와 테마는 다음 실행 시에도 유지됩니다.

### 2. Qwen3-TTS 로컬 보컬 음성 생성기 (0.6B 기본 성우 & 1.7B 새 음색 디자인)
- **기본 성우 (0.6B)**: 내장 성우(소희, 세레나, 비비안, 안나, 라이언 등)와 어조·감정 지시문을 조합해 보컬 참조용 음성을 생성합니다.
- **새 음색 디자인 (1.7B)**: 성우를 고르는 대신 원하는 목소리 특징(성별, 연령대, 질감, 분위기 등)을 자연어로 입력해 새로운 보컬 음색을 직접 합성합니다.
- **음성 목록 관리 및 이름 변경**: 생성된 음성을 오디오 스펙트럼 플레이어로 미리 듣고, 이름을 변경하거나 노래 만들기 탭의 보컬 음성 슬롯(1·2)으로 바로 등록할 수 있습니다.
- **음성파일 저장 (WAV / MP3) 및 메타정보 기록**: 생성된 음성을 `소리숲성우_` 접두사가 붙은 WAV(무손실) 또는 MP3(320kbps) 파일로 저장하며, 음악 파일과 동일하게 메타정보가 기록됩니다.

## 변경·개선

### 오디오 메타정보 Windows 호환성 개선
- Windows 탐색기에서 MP3(ID3v2.3 UTF-16LE 종단 처리) 및 WAV(RIFF `LIST/INFO` CP949 인코딩) 파일의 한글 메타정보가 깨져 보이던 문제를 해결했습니다.

### 다크모드 가독성 및 데스크톱 사용성 개선
- 노래·배경음악·효과음 결과 목록 및 내 컴퓨터 정보 창의 글자 크기를 키우고, 다크모드에서 가사·스타일 영역, 생성 엔진 준비 창, 전문가 튜닝 구분선, 녹색 강조 텍스트의 명암비를 개선했습니다.
- 상단 **업데이트** 버튼 클릭 시 확인 상태와 결과를 모달 창으로 안내하도록 개선했습니다.
- 기본 데스크톱 창 크기를 `1600 × 850`으로 조정하고, macOS `.dmg` 설치 창에 드래그 앤 드롭 안내 레이아웃을 적용했습니다.
