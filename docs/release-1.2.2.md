### 업데이트 내용

1. **K-EXAONE 가사 생성 - 종교 관련 장르 카테고리 대폭 추가**
   - 가사 생성 모달의 장르 스타일 선택 메뉴에 종교 음악 카테고리를 새롭게 추가했습니다.
   - `CCM/기독교 음악`, `찬송가/가스펠`, `불교음악/명상`, `성가/종교음악`을 선택하여 맞춤형 종교 가사를 손쉽게 생성할 수 있습니다.

2. **장르 직접 입력 기능 추가**
   - 장르 스타일에 **`직접 입력…`** 옵션을 추가했습니다.
   - 목록에 없는 장르나 세부 스타일(예: 워십, 가스펠, 국악가요, 찬양 등)을 사용자가 직접 입력창에 작성하여 정밀하게 가사를 작사할 수 있습니다.

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.2.2-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.2.2-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
