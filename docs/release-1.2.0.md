### 업데이트 내용

* 가사 만들기 기능 도입 - LG AI 연구원의 K-EXAONE 2.5 API 사용
* 노래 만들기에서 AI 가사 만들기 기능 상단으로 이동

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.2.0-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.2.0-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
