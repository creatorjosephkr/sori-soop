소리숲 1.3.8은 효과음 제작 기능 강화(영상 편집 프리셋 12종, 시간·제목 자동 연동, 전용 네거티브 프롬프트), 저장 음원 파일명 접두사 및 제작자 메타데이터 태그 추가, 앱 종료 시 임시 파일 정리 및 프로세스 완전 종료 처리를 적용합니다.

## 새로운 기능

### 효과음 만들기 프리셋 12종 및 시간·제목 자동 연동
- 영상 편집에 가장 자주 쓰이는 필수 효과음 12종 프리셋을 추가했습니다:
  - **화면 전환 슉 (2초)**, **자막 팝업 뿅 (2초)**, **화면 강조 쿵 (3초)**, **마우스 클릭 (2초)**, **카메라 셔터 (2초)**, **정답·알림 띵동 (3초)**, **오답 삐익 (2초)**, **키보드 타자음 (6초)**, **종이 넘김 (2초)**, **레코드 스크래치·반전 (2초)**, **긴장감 고조 라이저 (5초)**, **환호와 박수 (6초)**
- 효과음 프리셋 또는 상단 퀵 버튼(`화면전환 슉`, `자막 팝업`, `화면 강조`)을 선택하면 프롬프트 설명뿐만 아니라 **최적의 효과음 생성 시간(초)과 제목이 즉시 자동 설정**됩니다.
- 효과음 만들기 탭을 누르면 스타일 프리셋 접힘창이 자동으로 펼쳐져 바로 확인하고 선택할 수 있습니다.

### 저장 음원 파일 접두사 'SoriSoop_' 및 메타데이터 추가
- WAV 및 MP3 음원 다운로드 시 파일명 앞에 **`SoriSoop_` 접두사**가 자동으로 붙습니다. (예: `SoriSoop_화면 전환 슉.wav`, `SoriSoop_햇살이 머무는 아침.mp3`)
- 생성된 MP3 및 WAV 음원 파일에 아티스트 이름(`소리숲 (SoriSoop)`)과 앱 제작자 정보(`크리에이터 요셉 / creatorjoseph@kakao.com`) 메타데이터 태그를 추가하여 음원 관리와 저작자 식별이 편리해졌습니다.

### 앱 종료 시 임시 파일 정리 및 프로세스 완전 종료
- 앱이 닫힐 때 세션 동안 생성된 변환 임시 파일(`*.tmp`, `*-work`, `*.mp3`)을 자동으로 정리하여 디스크 용량을 낭비하지 않도록 개선했습니다.
- 창이 닫힐 때 백그라운드 프로세스가 남지 않고 프로세스가 완전히 종료되도록 안전한 종료 처리를 적용했습니다.

## 변경·개선

### 효과음 네거티브 프롬프트 강화 및 기본 선택
- 효과음 생성 시 음악이나 보컬이 섞이는 것을 차단하기 위해 **음악·멜로디·비트**, **보컬·음성·말소리** 제외 항목을 추가했습니다.
- 효과음 만들기 탭 진입 시 전용 제외 항목과 음질 보호 항목 총 11종이 **기본으로 자동 선택**되어, 원치 않는 음악 요소나 왜곡 없이 깨끗한 효과음을 얻을 수 있습니다.

### 앱 시작 시 기본 메뉴 및 결과 목록 동기화
- 앱을 처음 실행할 때 이전 세션의 목록 탭 대신, 기본 제작 메뉴인 **'배경음악 만들기'**에 맞춰 결과 목록도 **'배경음악 목록'**이 함께 열리도록 초기 상태를 일치시켰습니다.
- 메뉴를 전환할 때마다 하단 결과 목록도 동일한 유형으로 일치되어 표시됩니다.
