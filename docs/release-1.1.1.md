윈도우 환경에서 음악/노래 생성 상태 표시 영역에 불필요한 스크롤바가 나타나던 문제를 수정한 업데이트입니다.

- **생성 상태 영역 스크롤바 표시 수정**: 생성 진행 중 배경 애니메이션 효과(`::before` / `::after`)가 영역 밖으로 넘쳐 가로·세로 스크롤바를 유발하던 문제와, 2줄 이상의 상태 문구가 고정 높이를 초과해 세로 스크롤바가 생기던 현상을 해결했습니다.

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.1.1-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.1.1-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
