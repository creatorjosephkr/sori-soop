### 업데이트 내용

1. **K-EXAONE 가사 생성 기본 시간 연장 및 설정 기능 추가**
   - 저사양 컴퓨터에서 가사 생성 시 120초를 초과하여 오류가 발생하고 중단되던 문제를 해결하기 위해 기본 제한 시간을 10분(600초)으로 연장했습니다.
   - 가사 생성 모달 옵션에 대기 시간 선택 메뉴(10분, 15분, 20분, 제한 없음, 5분, 2분)를 추가하여 사용자의 컴퓨터 사양에 맞춰 설정할 수 있습니다.

2. **한글/영어 제목/가사 선택 기능 추가**
   - 가사 생성 옵션에 언어 선택(한국어/영어) 기능을 추가했습니다.
   - 영어를 선택하면 영어 전용 프롬프트 및 `[en]` 발음 태그가 적용되며, 미리보기 탭에 영문 표준 가사 및 보컬 엔진 가사가 표시됩니다.
   - 생성된 영문 가사를 메인 에디터에 적용하면 보컬 언어 설정도 자동으로 '영어'로 변경됩니다.

3. **Windows 11 설치 차단 해결 안내 및 설치 프로그램 메타데이터 보강**
   - Windows 11 환경에서 설치 시 Microsoft의 앱 검증 또는 SmartScreen으로 인해 설치가 차단되는 현상에 대응하여 설치 프로그램 메타데이터를 보강하고 안내를 추가했습니다.
   - **"Microsoft에서 확인한 앱이 아닙니다" 알림이 뜨는 경우:**
     - 창에서 **[그래도 설치]**를 클릭하여 진행합니다.
     - [그래도 설치] 버튼이 없는 경우: Windows **[설정] → [앱] → [고급 앱 설정] → [앱을 설치할 위치 선택]** 항목을 **[제한 없음]** 또는 **[어디서나]**로 변경하시면 정상 설치됩니다.
   - **"Windows의 PC 보호(SmartScreen)" 창이 뜨는 경우:**
     - **[추가 정보]**를 클릭한 후 나타나는 **[실행]** 버튼을 누르면 정상적으로 설치가 진행됩니다. (소리숲은 비영리 무료 오픈소스 프로그램으로, 고가의 기업용 디지털 서명 인증서가 미포함되어 표시되는 정상적인 보안 알림입니다.)

4. **업데이트 알림창 최신 릴리즈 페이지 연결 안내 개선**
   - 업데이트 알림창에서 다운로드 버튼을 누르면 설치 패키지가 바로 직접 다운로드되지 않고, 기본 웹브라우저에서 최신 GitHub 릴리즈 페이지(패키지 선택 및 설치 안내 화면)가 열리도록 연결 및 안내를 명확히 했습니다.

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.2.1-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.2.1-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
