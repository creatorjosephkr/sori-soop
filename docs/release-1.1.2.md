새 버전 업데이트 시 최신 릴리즈 페이지로 안전하게 이동하고 앱이 자동 종료되도록 개선한 업데이트입니다.

- **새 버전 다운로드 동작 개선**: 업데이트 알림 대화상자에서 '새 버전 다운로드'를 누르면 브라우저로 최신 GitHub 릴리즈 페이지를 열고 앱을 자동으로 종료합니다. 실행 중인 앱 파일 잠금으로 인한 설치 실패 없이 새 버전을 바로 설치·교체할 수 있습니다.
- **GitHub 릴리즈 보기 유지**: 앱을 종료하지 않고 릴리즈 내용만 확인하려는 경우 'GitHub 릴리즈 보기' 버튼으로 언제든 열어볼 수 있습니다.

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.1.2-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.1.2-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
