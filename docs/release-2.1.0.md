소리숲 2.1.0은 생성한 노래에서 아쉽거나 발음이 어색한 구간만 골라 다시 부르고, 가사·편곡·분위기를 단계별로 보완하며 원본과 바로 비교할 수 있는 **노래 다듬기(Song Workshop)** 전용 작업 공간을 새롭게 도입한 업데이트입니다.

## 새로운 기능

### 1. 노래 다듬기 (Song Workshop) 전용 작업 공간
- **4가지 다듬기 방식 지원**: 전체를 처음부터 다시 만들지 않고도 원하는 목적에 맞게 노래를 다듬을 수 있습니다.
  - **구간 다시 부르기 (특정 구간 다듬기)**: 발음이 뭉개지거나 어색한 특정 시간 구간만 지정해 다시 부릅니다.
  - **구간 다시 부르기 (뒷부분 이어서 연장)**: 곡 끝부분에 자연스럽게 이어지는 새로운 파트를 원하는 길이만큼 추가합니다.
  - **목소리·편곡 바꾸기**: 기존 멜로디와 흐름을 유지하면서 보컬 음색이나 악기·장르 편곡을 새롭게 바꿉니다.
  - **살짝 다른 느낌으로 다시 부르기**: 같은 곡을 바탕으로 미세한 창작 변주를 주어 새로운 버전을 만듭니다.
- **정밀한 오디오 제어 및 타임라인 눈금자**: 오디오 플레이어에 **`00:00` 처음으로 이동** 버튼을 추가했고, 구간 설정 바 위 **시간 눈금자**와 **시작점·끝점 핸들**, **선택한 구간만 들어보기** 기능으로 수정할 시간대를 정확하게 맞출 수 있습니다.
- **깔끔한 집중형 레이아웃**: 다듬기 화면 상단에는 버전 제목과 전환 메뉴만 간결하게 배치하고(기본/고급 모드 스위치 숨김), 왼쪽 작업 영역과 오른쪽 가사 영역이 화면 전체로 자연스럽게 함께 스크롤됩니다.

> **[스크린샷 1] 노래 다듬기(Song Workshop) 전체 작업 화면** (1단계 플레이어·타임라인 눈금자 + 오른쪽 가사 영역)을 여기에 추가해 주세요.

### 2. 원본 가사 자동 보존 및 누적 '수정·보완 내역' 탭
- **원본 가사 유지**: 구간 수정이나 다듬기를 실행해도 결과 노래의 가사에는 원본 전체 가사가 그대로 유지되어, 가사를 다시 복사·붙여넣기 할 필요가 없습니다.
- **누적 수정·보완 내역 기록**: 어느 시간 구간(`시작 ~ 끝`)을 어떤 가사·스타일로 다듬었는지 회차별로 자동 기록되며, **`가사창에 불러오기`** 버튼으로 이전 수정 가사를 언제든 다시 불러올 수 있습니다.
- **스크롤 없는 가사 확인 및 탭 구분**: 가사 영역을 **`원본 가사`** 탭과 **`수정·보완 내역`** 탭으로 분리했고, `원본 가사` 입력창은 내부 스크롤 없이 전체 가사가 한 번에 펼쳐지도록 개선했습니다. 완성된 **노래 목록 카드**에서도 같은 탭 구성으로 바로 확인할 수 있습니다.

> **[스크린샷 2] 오른쪽 가사 카드('원본 가사' / '수정·보완 내역' 탭 및 회차별 기록 화면)**를 여기에 추가해 주세요.

### 3. 원본 vs 다듬은 노래 바로 비교 듣기 및 버전 전환
- **실시간 비교 플레이어**: 다듬기가 끝나면 화면 하단에 원본 노래와 방금 다듬은 노래 플레이어가 나란히 표시되어 두 버전을 바로 번갈아 들어볼 수 있습니다.
- **이번 수정 기록 & 이어서 다듬기**: 비교 카드 안에 방금 적용한 수정 구간·내용이 함께 표시되며, 마음에 들면 **WAV / MP3**로 저장하거나 **`이 노래로 이어서 다시 다듬기`** 버튼을 눌러 추가 수정 작업을 계속할 수 있습니다.
- **상단 버전 전환**: 같은 원본에서 파생된 여러 수정 버전을 상단 **버전 전환** 선택창에서 빠르게 오가며 작업할 수 있습니다.

> **[스크린샷 3] 원본 vs 다듬은 노래 비교 듣기 카드 및 이번 수정 기록 화면**을 여기에 추가해 주세요.

## 노래 다듬기 간단한 사용 방법

1. **노래 다듬기 열기**
   - 완성된 노래 결과 카드 아래의 **`노래 다듬기`** 버튼을 클릭합니다. (보컬 노래와 연주곡 모두 지원합니다.)

   > **[스크린샷 4] 음악 목록 결과 카드의 '노래 다듬기' 버튼 위치**를 여기에 추가해 주세요.

2. **1단계: 원본 노래 들으며 수정할 구간 맞추기**
   - 상단 플레이어의 재생/처음으로(`00:00`) 버튼으로 노래를 재생하면서, 아래 타임라인 눈금자의 선택 영역을 드래그하거나 양쪽 손잡이를 끌어 수정할 구간을 정합니다.
   - 노래가 재생 중인 위치에서 **`현재 위치를 시작점으로`** / **`현재 위치를 끝점으로`** 버튼을 누르면 해당 시점으로 바로 고정되며, **`선택한 구간만 들어보기`**로 구간이 자연스러운지 반복 확인할 수 있습니다.
3. **2단계: 다듬기 방법 고르기 & 가사·스타일 보완**
   - 원하는 다듬기 방식(구간 다시 부르기 · 목소리/편곡 바꾸기 · 살짝 다른 느낌으로 다시 부르기)을 선택합니다.
   - 보컬 노래라면 오른쪽 **`원본 가사`** 탭에서 전체 가사 중 문제가 있는 구간만 소리 나는 대로 수정하고(예: `빛나는` → `빈나는`), 필요한 경우 스타일 프롬프트나 보컬 음색 참조도 함께 조정합니다.
4. **3단계: 다듬은 노래 만들기 및 비교·저장**
   - **`다듬은 노래 만들기`** 버튼을 눌러 생성을 시작합니다.
   - 완성된 뒤 아래 비교 영역에서 원본과 새 버전을 직접 들어보고 **WAV(무손실) / MP3(320kbps)**로 저장하거나, **`이 노래로 이어서 다시 다듬기`**로 다음 구간 보완을 이어갑니다.
