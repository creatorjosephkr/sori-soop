소리숲 1.3.0은 가사 없는 Instrumental 연주곡 생성, 유형별 입력·결과 분리, BPM 설정, 선택형 네거티브 프롬프트와 앱 전용 휴지통 관리를 추가합니다.

## 새로운 기능

### 가사 없는 Instrumental 연주곡
- 노래 만들기 상단에서 **보컬 노래 / Instrumental 연주곡**을 버튼으로 선택할 수 있습니다.
- Instrumental을 선택하면 ACE-Step의 연주곡 옵션을 활성화하고, 기존에 입력한 가사와 보컬 언어는 생성에 사용하지 않습니다.
- 연주곡에서는 가사 입력과 작사 도구를 숨기고 음악 길이를 직접 지정합니다.
- 연주곡용 프리셋은 보컬·창법 항목을 제외하고 악기 중심 설명을 사용합니다.
- 배경음악 만들기 상단에 노래 만들기의 Instrumental 기능을 안내하는 박스를 추가했습니다.

### BPM 선택과 직접 입력
- 배경음악과 Instrumental 연주곡에서 속도(BPM)를 선택하거나 30~300 범위의 정수로 직접 입력할 수 있습니다.
- 선택한 BPM을 음악 설명에 합쳐 생성에 사용합니다. 같은 BPM은 중복 추가하지 않고, 설명의 BPM과 선택값이 다르면 수정 안내를 표시합니다.
- BPM을 포함한 설명이 2,000자를 넘으면 설명을 줄이도록 안내합니다.
- 배경음악의 속도 설정은 음악 설명 입력란 아래에 표시합니다.

### 앱 전용 휴지통 관리
- 각 결과 목록의 **선택 삭제** 옆에 **휴지통** 버튼을 추가했습니다.
- 현재 목록에 맞는 삭제 항목을 먼저 보여주며, 배경음악·노래·연주곡·효과음 또는 전체 목록으로 바꿔 볼 수 있습니다.
- 제목·종류·삭제 일시·파일 용량과 목록의 총용량을 확인할 수 있습니다.
- 목록 위·아래의 **휴지통 비우기** 버튼으로 확인창에 표시된 항목만 영구 삭제합니다. 다른 종류의 휴지통과 정상 보관 중인 결과는 유지합니다.
- 일부 파일을 지우지 못한 경우 실패한 항목 수를 안내합니다.

## 변경·개선

### 유형별 입력과 결과 목록
- 배경음악·보컬 노래·연주곡·효과음의 제목·음악 설명·프리셋을 각각 유지합니다. 유형을 바꾸면 해당 유형에 입력한 내용을 복원합니다.
- **새로 만들기**로 현재 작업의 제목·설명을 비워도 다른 유형의 제목·설명은 유지합니다.
- 배경음악·노래·효과음 만들기 탭을 선택하면 해당 결과 목록도 함께 열립니다.
- 노래 목록 안에 **노래 / 연주곡** 탭을 추가했습니다. 노래 유형 버튼을 선택하면 해당 목록으로 전환합니다.
- 목록별 페이지 위치를 따로 유지하며 삭제로 마지막 페이지가 비면 유효한 페이지로 이동합니다.
- 기존 보컬 노래 기록은 노래 탭에 표시합니다. 화면의 연주곡 표기는 ‘MR’ 대신 ‘연주곡’으로 통일했습니다.

### 선택형 네거티브 프롬프트
- 기존 직접 입력란과 기본값 복원 버튼을 제거하고, 항목별 한국어 설명이 있는 체크박스로 바꿨습니다.
- 기본적으로 접혀 있으며 펼쳐서 항목을 선택하거나 해제할 수 있습니다.
- 배경음악·연주곡: **보컬·말소리**, **음정 불안정**을 제외한 항목을 기본 선택합니다.
- 보컬 노래: 제공하는 모든 항목을 기본 선택합니다. 발음·기계적인 보컬 관련 항목을 포함합니다.
- 효과음: 모든 항목을 기본 해제합니다. 아무 항목도 선택하지 않으면 네거티브 프롬프트를 사용하지 않습니다.
- 유형별 선택값을 따로 유지하며, 선택한 항목만 생성 요청에 전달합니다.

## 오류 수정·검증
- 노래·연주곡 분리 후 생성 중 목록 갱신이 중단되던 변수 참조 오류를 수정했습니다. 대기·생성 중 애니메이션, 제목, 생성 단계, 경과 시간과 중단 버튼을 표시합니다.
- 네거티브 프롬프트·BPM 기능 파일의 제공 경로 누락으로 발생하던 `GenerationOptions.render` 오류를 수정했습니다.
- 안내 문구의 강조 단어가 문장 밖으로 밀려나던 표시 문제를 수정했습니다.
- 네이티브 화면 검증에 입력 분리·프리셋 복원·목록 필터·페이지 이동·생성 중 상태·휴지통 조회 및 비우기를 추가했습니다.
- 서버 검증에서 화면에 연결된 모든 스크립트가 제공되는지 확인하고, 패키지 실행 검증에서도 네거티브 프롬프트 항목 로딩을 확인합니다.

## 설치·데이터 안내
- 기존 앱을 종료한 뒤 새 버전을 설치하세요. 모델·설정·생성 결과와 기존 휴지통은 유지됩니다.
- 앱 휴지통은 운영체제 휴지통과 별개이며 사용자 홈의 `.local-music-studio/trash`에 보관합니다. **휴지통 비우기는 영구 삭제이며 복구할 수 없습니다.**
- Mac: `SoriSoop-1.3.0-macos-arm64.dmg` — Apple Silicon / macOS 14 이상.
- Windows: `SoriSoop-1.3.0-windows-x64-setup.exe` — Windows 10(버전 2004 이상)/11 x64.
- K-EXAONE 가사 생성의 지연 요인은 별도로 분석했으며, 이번 버전에서 API 생성 속도나 가사 생성 방식을 변경하지는 않았습니다.

앱 소스는 MIT 라이선스이며 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
