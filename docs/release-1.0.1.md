앱 실행 시 ‘Address already in use’ 오류가 나던 문제를 수정했습니다.

- 기본 연결 주소가 사용 중이면 사용 가능한 주소를 자동으로 선택합니다.
- 같은 데이터 폴더를 사용하는 소리숲 서버가 이미 실행 중이면 확인 후 해당 서버를 재사용합니다. 생성 작업과 기록이 서로 충돌하지 않도록 백엔드를 하나만 실행합니다.
- 실제로 주소를 점유한 상태에서 배포용 앱과 네이티브 화면이 정상 실행되는지 검사하도록 빌드 테스트를 보강했습니다.
