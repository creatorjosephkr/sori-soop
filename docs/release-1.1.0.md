성능·기능별 신규 모델(`Stable Audio 3 Medium` / `Small-SFX`), 효과음 제작 모드, 네거티브 프롬프트, 가사·발음 품질 개선 및 UI 다듬기를 반영한 업데이트입니다.

- **성능/기능별 모델 추가**: 최대 380초 고품질 배경음악을 생성하는 `Stable Audio 3 Medium` 모델과 효과음 전용 `Stable Audio 3 Small-SFX` 모델을 추가하고, 설정 화면에서 원클릭 추가 설치를 지원합니다.
- **효과음 생성 기능 추가 (`효과음 만들기`)**: 전용 제작 탭, 효과음 스타일·공간감 프리셋, 1~120초 길이 조절 및 `효과음 목록` 탭을 신설했습니다.
- **네거티브 프롬프트 설정 추가**: 원치 않는 소리와 음질 저하를 배제하는 네거티브 프롬프트 입력창과 권장 기본값 복원 버튼을 추가했습니다.
- **가사 누락 및 발음 부정확 개선**: `ACE-Step 1.5` 곡 구성(`5Hz LM`) 및 오디오 합성(`shift=3.0`) 파라미터를 최적화하고, 한국어 발음(G2P)·음절 수 규칙 기반 작사 요청문 및 `가사 생성 가이드` 모달을 추가했습니다.
- **샘플 노래 생성 및 UI 다듬기**: 왼쪽 사이드바 `샘플 노래 만들기` 버튼 추가, 운영체제 이름·버전 표시, 목록 페이지당 10개 표시, 가사창 높이 확대, 설명 입력 도움말 모달 전환, 기본 최대 게인 `-8dB` 적용 및 한 줄 설정 레이아웃으로 정돈했습니다.
