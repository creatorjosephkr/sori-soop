### 업데이트 내용

1. **Windows 11 운영체제 정확한 감지 및 표시**
   - 윈도우 11 환경에서 시스템 정보에 'Windows 10'으로 잘못 표시되던 문제를 수정하여, 'Windows 11'로 정확하게 표시되도록 개선했습니다.

2. **음악/노래 생성 시간 표시 개선 (`분:초 (전체 초)`)**
   - 생성 진행 중 경과 시간 및 생성 완료 후 상세 정보의 처리 시간을 기존 단순 초 단위에서 `분:초 (전체 초)` 형식(예: `2:05 (125초) 경과`)으로 가독성을 높였습니다.

3. **생성 목록 체크박스 및 일괄 삭제 기능 추가**
   - 생성 결과 목록 각 항목 앞에 체크박스를 추가하고, 상단에 `전체 선택` 및 `선택 삭제 (N개)` 버튼을 도입하여 여러 생성 결과를 한 번에 편리하게 삭제할 수 있습니다.

4. **노래 생성 목록 기본 개수 20개로 확대**
   - 보컬 노래 목록의 페이지당 기본 표시 개수를 10개에서 20개로 확대했습니다. (배경음악 및 효과음 목록은 기존 10개 유지)

**업데이트:** 기존 앱을 종료한 뒤 새 파일로 설치·교체해 주세요. 기존 음악·노래·설정·모델 데이터는 유지됩니다.

- **Mac:** `SoriSoop-1.2.3-macos-arm64.dmg` → Applications로 복사. Apple Silicon / macOS 14 이상.
- **Windows:** `SoriSoop-1.2.3-windows-x64-setup.exe` 실행 → 설치 위치 선택 → 설치 완료 후 소리숲 실행. Windows 10(버전 2004 이상)/11 x64 대상.
- `SHA256SUMS.txt`로 다운로드 파일의 무결성을 확인할 수 있습니다.

앱 소스는 MIT 라이선스이고 모델·폰트·실행 구성요소에는 개별 이용 조건이 적용됩니다.
